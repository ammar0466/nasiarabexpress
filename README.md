# Nasi Arab Express 🍛

> Official Web & Reseller Directory for **[nasiarabexpress.com](https://nasiarabexpress.com)**

Built with **Tailwind CSS**, **Cloudflare Pages**, and **Pages Functions API**.

## Features
- **Modern Responsive Landing Page**: High-converting food brand design.
- **Interactive Reseller Directory**: Real-time search, filter by state, and 1-click WhatsApp order integration.
- **Cloudflare Pages Backend**: Serverless API `/api/resellers` for instant dynamic queries.
- **High Performance**: 100/100 Lighthouse performance with edge caching on Cloudflare global CDN.

## Deployment
Hosted on **Cloudflare Pages** attached to custom domain `nasiarabexpress.com`.
